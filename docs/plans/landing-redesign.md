# GGbondai 落地页重做方案

日期：2026-10-30
状态：主要决定已确认（见第 11 节），尚未动代码

本文档取代 `plans/frontend-refactor.md` 和 `archive/ggbond-ip-reference.md` 里关于角色和配色的描述。那两份文档说猪猪侠是"粉色皮肤、紫色战甲"，这是错的。

## 1. 目标

- 落地页去掉大段说明文字，只保留品牌名、一句口号和行动按钮。
- 页面中央放一个会动的猪猪侠形象，各大厂商的模型图标沿轨道环绕它转动，效果参考 A6api 首页（中间的地球换成猪猪侠）。
- 整站配色改成猪猪侠真实的红、黄、肤色。

## 2. 角色与配色

### 2.1 角色外形（按你给的截图）

- 红色连帽头套包住整个头，只露出脸；头套两侧各有一只小耳朵。
- 头套额头位置有两道黄橙色的眉形装饰。
- 脸是浅肉色，圆脸，粉色猪鼻子，两个鼻孔。
- 黑色大圆眼睛，带白色高光，表情是笑的。
- 身体穿的也是红色衣服。

### 2.2 色板（从截图取色，实现时用设计稿再校准）

| 角色 | 用途 | 色值 |
|------|------|------|
| 头套红 | 品牌主色、主按钮、强调 | `#E2231A` |
| 深红 | 悬停、暗部、白底上的文字 | `#B3150F` |
| 眉饰黄 | 高光、徽章、能量光效 | `#FFB703` |
| 浅黄 | 光晕、背景点缀 | `#FFD866` |
| 肤色 | 角色的脸、浅色卡片底 | `#F6CDB0` |
| 鼻子粉 | 角色的鼻子、少量点缀 | `#EBA08A` |
| 眼睛黑 | 正文、描边 | `#1F1410` |

对比度：白字配 `#E2231A` 约 4.6:1，配 `#B3150F` 约 7:1，都达到 WCAG AA。黄色只配深色文字。实现时用脚本复测一遍。

当前代码里的粉紫色阶（`primary`、`accent`、`ggbond-*`）会整体换成上面这套。`primary` 这个名字不变，所以全站已经在用 `primary-*` 的地方（大约 800 处）会自动跟着变色。

### 2.3 背景（已定：浅色）

首页用浅色暖底：从肤色浅调 `#FFF6EF` 渐变到白色，中间叠一层很淡的红黄光晕。轨道线用半透明红色，模型图标放在白色圆角小方块里，带柔和阴影，在浅色底上也能看清。全站其他页面同样是浅色，保留暗色模式切换。

## 3. 版权（暂不考虑）

猪猪侠是广东咏声动漫（WinSing Animation）的 IP（[Wikipedia: GG Bond](https://en.wikipedia.org/wiki/GG_Bond)）。按你的决定先不处理；以后要对外收费时再回来看。

### 3.1 形象怎么做

| 方式 | 还原度 | 能做的动效 | 说明 |
|------|--------|-----------|------|
| 手绘扁平 SVG（推荐） | 一眼能认出是猪猪侠，但是扁平卡通画风，没有原片的 3D 光影质感 | 全部：眨眼、眼睛跟随鼠标、耳朵抖动、表情变化、变身闪光 | 头套、眉饰、脸、鼻子、眼睛分图层画，每层都能单独动 |
| 原图抠图 PNG | 和原片一样 | 只能整体动：浮动、缩放、光晕 | 需要一张高清、背景干净的原图；你给的截图分辨率太低，放大后会糊 |
| 位图自动转矢量 | 介于两者之间 | 很少 | 生成的路径又多又乱，没法分层动画，不推荐 |

先画扁平 SVG，给你看静态效果。如果你觉得不像，再换成高清原图抠图，页面结构不用改。

## 4. 落地页结构

```
┌──────────────────────── 导航（半透明胶囊） ────────────────────────┐
│ Logo GGbond AI     首页 · 模型 · 文档            语言 主题 登录 注册 │
└─────────────────────────────────────────────────────────────────────┘

   左侧精选模型卡                                      右侧精选模型卡
   [图标] 对话 / 模型                                  [图标] 视频 / 模型
   Claude Opus                  ◯ 外圈轨道 ◯           Gemini Pro
   一句话说明                ◯   猪猪侠    ◯           一句话说明
                             ◯   + 光晕    ◯
                               ◯ 内圈轨道 ◯
                          口号：一个 Key，接入全部大模型
                                [ 立即体验 ]

                              向下滚动 ↓（可选）
└──────────────────────────── 极简页脚 ────────────────────────────────┘
```

- 首屏占满一屏，中间是猪猪侠，周围有两到三圈轨道，模型图标沿轨道转。
- 两侧各有一张精选模型卡，在 Claude、GPT、DeepSeek 三个精选模型之间轮换，每 4 秒换一次；轮换时轨道上对应的图标高亮。
- 文字只剩三处：口号一句、副标题一句、按钮一个。
- 现有首页的"平台能力、支持模型、接入步骤、计费说明"四个区块全部删除。页脚只保留版权和法律文档链接。
- 后台配置的 `home_content`（自定义首页 HTML 或 iframe）继续优先生效，这个逻辑不动。

## 5. 动效设计

| 元素 | 动效 | 实现方式 |
|------|------|----------|
| 猪猪侠待机 | 上下轻微浮动、每隔几秒眨眼、头套耳朵偶尔抖一下 | SVG 分层，CSS keyframes |
| 猪猪侠互动 | 眼睛跟着鼠标转；悬停时笑、眉饰发光；点击时做一个"变身"闪光 | 小段 TS 计算瞳孔偏移，加 CSS 过渡 |
| 轨道 | 两到三圈椭圆轨道，带透视倾斜（像参考站那样从斜上方看），各圈转速和方向不同 | CSS 3D：`rotateX` 让轨道倾斜，`rotateZ` 让它转；图标反向旋转，保持正面朝向观众 |
| 模型图标 | 沿轨道转动；悬停时停下、放大、显示模型名 | 同上，悬停时暂停对应轨道的动画 |
| 背景 | 浅色底上有细小的红黄光点缓慢闪烁，角色身后有红黄光晕呼吸 | CSS 渐变加少量绝对定位的点 |
| 精选卡 | 每 4 秒淡入淡出轮换 | Vue `<Transition>` |

技术取舍：

- 不引入 three.js、Lottie 等新依赖。纯 CSS 和 SVG 就能做出参考站的效果，体积小，也好改。
- 系统开启"减少动态效果"（`prefers-reduced-motion`）时，停掉轨道旋转和浮动，只保留静态布局。
- 只用 `transform` 和 `opacity` 做动画，避免触发重排。
- 页面切到后台标签时暂停动画，省电。

## 6. 模型数据

- 图标直接用现有的 `src/components/common/ModelIcon.vue`，不加新包。
- 轨道上展示 `ModelIcon.vue` 里的全部 27 个厂商：claude、openai、gemini、deepseek、qwen、zhipu、doubao、moonshot、xai、mistral、meta、minimax、cohere、yi、wenxin、spark、hunyuan、perplexity、midjourney、suno、jina、ollama、openrouter、ai360、dify、coze、cloudflare。分到三圈轨道上，外圈放得最多。
- 精选模型：Claude、GPT、DeepSeek。
- 后端原生支持的上游平台是 Anthropic、OpenAI、Gemini、Grok、Antigravity（见 `backend` 里的 `Platform*` 常量）。DeepSeek、通义等其他厂商要靠配置 OpenAI 兼容的上游账号才能用。展示列表写在 `src/views/home/showcaseModels.ts` 里，哪个实际没接，删掉那一行就行。
- 以后可以改成从后台读取实际可用的模型。这需要一个不用登录的公开接口，第一版不做。

## 7. 响应式

- 桌面端（≥1024px）：完整布局，两侧有精选卡，三圈轨道。
- 平板端：两侧卡片移到轨道下方，保留两圈轨道。
- 手机端：一圈轨道，图标减少到 8 个左右，猪猪侠缩小；文字和按钮放在轨道下方。

## 8. 文案

中英文都改，写在 `src/i18n/locales/{zh,en}/home-ggbond.ts` 里。

口号候选（突出性价比）：

1. 一个 Key，用遍全球大模型，价格更低
2. 顶级大模型，平价随心用
3. 同样的 Claude 和 GPT，更低的价格
4. 少花钱，多调用，一个 Key 全搞定

副标题草稿：按量计费，人民币结算，Claude、GPT、DeepSeek 一键接入。

按钮：已登录显示"进入控制台"，未登录显示"立即体验"。

"比官方便宜"这类说法要和你的实际定价一致，否则别写具体数字或百分比。首页不再用的旧文案 key 会一起删掉。

## 10. 实施步骤

1. 定下第 3 节的版权方案和第 2.3 节的首页背景。
2. 画猪猪侠 SVG 头像，先发静态图给你确认长相。
3. 换配色，跑对比度脚本和全部测试。
4. 实现轨道、图标和精选卡，接上动效。
5. 重写首页、改文案、适配手机。
6. 验证：类型检查、单元测试、在桌面和手机宽度下截图给你看，再检查减少动态效果模式。
