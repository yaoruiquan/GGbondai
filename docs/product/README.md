# 产品与功能规格

描述 GGbondai **应该**怎么表现：面向谁、提供什么能力、业务规则是什么。只写个人项目当前或已确认的行为，不放公司环境配置或运行数据。

## 建议拆分

| 文档 | 内容 |
|------|------|
| `prd.md` | 产品定位、目标用户、核心场景、商业模式（充值/订阅/定价） |
| `features/<功能名>.md` | 单个功能的 spec，用 [`templates/feature-spec.md`](../templates/feature-spec.md) |

功能 spec 可按模块分：用户与认证、API Key、计费与充值、渠道与账号池、网关转发、管理后台。
