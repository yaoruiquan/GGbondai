# 设计规范

品牌、视觉和交互规范，是前端实现的依据。

## 建议拆分

| 文档 | 内容 |
|------|------|
| `brand.md` | 品牌名、口号、Logo、猪猪侠角色外形与使用规范 |
| `colors.md` | 色板、语义色、对比度要求、暗色模式 |
| `components.md` | 通用组件的外观与交互规范 |
| `pages/<页面>.md` | 关键页面设计（首页、控制台、充值页） |
